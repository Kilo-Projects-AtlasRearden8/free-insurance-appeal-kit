## How to use

1. Open any `.html` file in your browser (Chrome, Edge, Firefox, Safari).
2. Fill in the fields on screen.
3. Print (Ctrl+P / Cmd+P) or save as PDF. Blank fields print as lines you can write on by hand.
4. No account, no signup, nothing is uploaded or saved online. Everything stays on your device.
